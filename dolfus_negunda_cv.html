Outbound Logistics Simulation Analytics Platform
Simulation Consultant & Analytics Engineer · Heavy Industrials
2025 – 2026

End-to-end simulation analytics ecosystem evaluating a high-volume outbound logistics chain across rail, dual-port, and vessel systems — built on a 48-node discrete event simulation model. Sole analytics engineer responsible for database architecture, automation workflows, cost modelling engine, AI agent deployment, and client-facing sprint delivery.

  • Automated Simulation Workflow Engine: parameterised Excel-driven scenario creation, atomic bulk-insert transactions, idempotent OAT sensitivity generation (±20% across ten parameters), and FK-ordered cascade deletion with rollback-on-error — reducing scenario setup from hours to minutes.
  • Scalable Output Ingestion Pipeline: processed thousands of simulation CSV files per run via parallel ThreadPoolExecutor reads, SQL-side deduplication via staging tables, and fast_executemany batched inserts with pre-flight sync and full re-run safety.
  • Enterprise Simulation Database Architecture: 48-node Azure SQL schema with thirteen dimension/fact tables, seven Power BI views, warmup-excluded pre-aggregated summary tables, and a pre-computed OAT tornado sensitivity view — enabling sub-second KPI queries across stochastic replications.
  • Production-Grade Cost Modelling Engine: modular Python package with CLI covering four cost categories, event-based demurrage calculation, port fixed-cost scaling, replication-level aggregation, and multi-sheet Excel report generation.
  • AI Analytics Agent Design & Deployment: two principal-level AI agents with anti-hallucination contracts, dynamic procedural memory across nine categories, schema-grounded SQL generation, and role-specific specialisations.
  • Client Analytics Delivery Framework: four-sprint structured analysis (Monte Carlo, sensitivity, cost model) with Power BI dashboards, tornado charts, and executive sprint presentations informing port allocation, buffer sizing, and fleet decisions.
